# 📝 MEVN Blog Application (S87-S89)

A full-stack blog application built using the **MEVN Stack (MongoDB, Express, Vue, Node.js)**.  
This project supports user authentication and full CRUD operations for blog posts.

---

## 🚀 Features

### 👤 Authentication
- User registration (email, username, password)
- Secure login system
- Password hashing using bcrypt
- JWT authentication

### 📝 Blog Posts
- Create blog posts
- View all posts
- View single post
- Update posts
- Delete posts (author or admin only)

### 👥 User Roles
- **Users**: Can create and manage their own posts
- **Admin**: Can delete any post

---

## 🛠 Tech Stack

### Frontend
- Vue 3
- Vite
- Vue Router
- Axios

### Backend
- Node.js
- Express.js
- MongoDB + Mongoose
- JWT Authentication
- Bcrypt
